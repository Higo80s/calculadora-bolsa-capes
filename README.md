# Calculadora de Prazo de Bolsa CAPES

Ferramenta desktop para validar pedidos de bolsa CAPES na modalidade **Demanda Social**, com base na **Portaria CAPES nº 76/2010**.

## 🎯 Funcionalidades

- Valida se o prazo solicitado está dentro do **período regular** do curso:
  - **Mestrado**: até 24 meses após o ingresso
  - **Doutorado**: até 48 meses após o ingresso
- Calcula automaticamente o **número máximo de meses com pagamento**
- Indica o **último mês de pagamento** (ex: início em mar/2025 → fim em fev/2027 para mestrado)
- Interface gráfica simples e intuitiva

## 🖥️ Requisitos

- Windows (ou qualquer SO com Python)
- Python 3.8 ou superior
